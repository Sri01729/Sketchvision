# 💡 SketchVision

**Category:** AI-powered Web Application
**Description:**
SketchVision is a web application that transforms hand-drawn sketches and text annotations into stunning AI-generated images using OpenAI’s DALL·E 3. It bridges the gap between simple sketches and professionally rendered digital art, empowering users to bring their ideas to life with ease.

---

### Frontend
- React 19
- TypeScript
- Tailwind CSS
- Radix UI
- HTML5 Canvas

### Backend
- Node.js

### AI Integration

- DALL·E 3

## 🧠 Core Features
- Interactive sketching canvas with annotation support
- AI-generated image output based on user drawings and prompts
- Smart prompt generation using GPT-based templates
- Real-time image rendering with DALL·E 3
- User gallery for viewing and managing past creations
- Local storage-based persistence across sessions
- Fully responsive design for both desktop and mobile devices
